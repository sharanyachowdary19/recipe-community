About the project

A beginner-friendly full-stack recipe search app.

Recipe Finder demonstrates how a browser, an Express.js backend, and a Supabase PostgreSQL database work together. The browser never receives the privileged database key.

What you can do

  • Search recipes by name or ingredient.
  • Filter by category and maximum cooking time.
  • Open complete recipe details.
  • Store recipe data permanently in PostgreSQL.
  • Manage recipes through protected admin API endpoints.
